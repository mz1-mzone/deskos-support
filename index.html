DeskOS

A desktop-style workspace for iPhone and an external display.

Getting started

  1. Connect your iPhone to a display using USB-C or a compatible HDMI adapter.
  2. Open DeskOS. The workspace appears on the monitor and the iPhone becomes its trackpad and keyboard surface.
  3. Open Finder, Browser, Notes, Calculator, Settings, or web shortcuts from the Dock.

Common questions

Can DeskOS show every file on my iPhone?
iOS lets DeskOS browse its own documents and folders you explicitly select with the system file picker. Other apps' private files remain protected.

Are WhatsApp, ChatGPT, and Google apps installed inside DeskOS?
These shortcuts open their websites in DeskOS. Website features, sign-in, media playback, and file editing depend on each provider.

Can DeskOS run installed iPhone apps in windows?
iOS does not let one App Store app embed arbitrary installed apps. DeskOS windows contain its built-in tools and supported websites.

How do I type?
A connected hardware keyboard types directly into the focused DeskOS field. Without one, select a text field to show the iPhone keyboard.
